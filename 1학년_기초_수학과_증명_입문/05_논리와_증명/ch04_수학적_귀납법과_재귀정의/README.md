# 논리와 증명 04. 수학적 귀납법과 재귀정의

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 1+...+n 공식이 n에서 n+1로 이어짐을 계산한다.
- 실제 응용 예제: 재귀적으로 증가하는 비용 모델의 총 비용을 추정한다.

## 실행
```powershell
jupyter lab
```
