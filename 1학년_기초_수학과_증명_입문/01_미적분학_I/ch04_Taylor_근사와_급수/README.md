# 미적분학 I 04. Taylor 근사와 급수

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: sin(x)의 Taylor 다항식 차수가 커질수록 근사가 개선되는 것을 비교한다.
- 실제 응용 예제: 작은 각도 근사를 사용해 진자의 빠른 계산 모델을 만든다.

## 실행
```powershell
jupyter lab
```
