# 미적분학 I 01. 함수와 극한

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: sin(x)/x가 x=0에서 1로 가까워지는 모습을 표와 그래프로 확인한다.
- 실제 응용 예제: 카메라 노이즈가 있는 센서값을 작은 구간에서 안정적으로 근사한다.

## 실행
```powershell
jupyter lab
```
