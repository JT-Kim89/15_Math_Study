# 확률과 통계 입문 02. 이산/연속 확률변수

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 이산 분포 막대그래프와 연속 밀도곡선을 비교한다.
- 실제 응용 예제: 재고 수요량과 대기시간을 서로 다른 확률변수로 모델링한다.

## 실행
```powershell
jupyter lab
```
