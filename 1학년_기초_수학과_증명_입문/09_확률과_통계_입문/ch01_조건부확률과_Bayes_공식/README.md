# 확률과 통계 입문 01. 조건부확률과 Bayes 공식

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 동전의 앞면 확률에 대한 사후분포를 갱신한다.
- 실제 응용 예제: 검사 양성 결과 이후 실제 질병 확률을 갱신해 해석한다.

## 실행
```powershell
jupyter lab
```
