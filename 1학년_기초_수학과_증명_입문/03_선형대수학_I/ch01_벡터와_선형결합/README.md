# 선형대수학 I 01. 벡터와 선형결합

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 두 벡터의 선형결합이 평면의 격자를 어떻게 채우는지 본다.
- 실제 응용 예제: 두 재료 배합 비율로 가능한 색상/성분 조합을 시각화한다.

## 실행
```powershell
jupyter lab
```
