# 수학을 위한 프로그래밍 03. 난수 시뮬레이션

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 동전과 주사위 실험을 반복해 경험적 분포를 만든다.
- 실제 응용 예제: 품질검사에서 불량률 추정의 변동성을 시뮬레이션한다.

## 실행
```powershell
jupyter lab
```
