# 수학을 위한 프로그래밍 01. Python 수치 배열과 시각화

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 격자 간격을 줄일 때 수치 미분 오차가 어떻게 변하는지 본다.
- 실제 응용 예제: 센서 샘플링 간격을 정할 때 정확도와 계산량의 균형을 잡는다.

## 실행
```powershell
jupyter lab
```
