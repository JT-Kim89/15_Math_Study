# 이산수학 03. 점화식과 생성함수

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: Fibonacci 수열을 점화식과 조합적 경로 수로 연결한다.
- 실제 응용 예제: 사용자 성장 모델의 누적 규모를 재귀식으로 예측한다.

## 실행
```powershell
jupyter lab
```
