# 집합론 기초 03. 가산성과 무한집합

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 자연수와 짝수의 일대일 대응을 수열로 표현한다.
- 실제 응용 예제: 무한히 생성되는 ID 체계를 충돌 없이 세는 방법을 설계한다.

## 이론 보강
