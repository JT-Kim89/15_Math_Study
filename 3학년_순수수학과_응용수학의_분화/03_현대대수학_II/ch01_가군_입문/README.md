# 현대대수학 II 01. 가군 입문

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 벡터공간을 일반화한 가군의 생성 관계를 그림으로 표현한다.
- 실제 응용 예제: 선형 제약을 가진 자료 구조를 대수적으로 모델링한다.

## 실행
```powershell
jupyter lab
```
