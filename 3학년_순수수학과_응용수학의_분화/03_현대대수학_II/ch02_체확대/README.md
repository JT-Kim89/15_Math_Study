# 현대대수학 II 02. 체확대

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 유리수에 sqrt(2)를 붙일 때 생기는 켤레 구조를 본다.
- 실제 응용 예제: 대수방정식 해를 표현하기 위해 필요한 수 체계를 확장한다.

```powershell
jupyter lab
```
