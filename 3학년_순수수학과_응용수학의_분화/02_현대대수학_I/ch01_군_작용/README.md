# 현대대수학 I 01. 군 작용

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 작은 군이 집합 위에서 원소를 어떻게 이동시키는지 본다.
- 실제 응용 예제: 퍼즐 상태공간에서 가능한 움직임을 대칭으로 묶는다.

## 실행
```powershell
jupyter lab
```
