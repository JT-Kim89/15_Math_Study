# 위상수학 03. 콤팩트성과 연결성

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 점구름에서 연결 성분과 덮개 크기를 근사한다.
- 실제 응용 예제: 무선망 커버리지의 빈틈과 연결성을 점검한다.

## 실행
```powershell
jupyter lab
```
