# 위상수학 02. 연속사상과 위상동형

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 찢거나 붙이지 않는 변형이 연결성을 보존함을 시각화한다.
- 실제 응용 예제: 형태가 다른 센서 배치가 같은 네트워크 구조를 갖는지 판단한다.

## 실행
```powershell
jupyter lab
```
