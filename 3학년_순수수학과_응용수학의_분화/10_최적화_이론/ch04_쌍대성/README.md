# 최적화 이론 04. 쌍대성

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 원문제와 쌍대문제의 목적값 관계를 시각화한다.
- 실제 응용 예제: 자원의 그림자가격을 해석해 의사결정에 활용한다.

## 실행
```powershell
jupyter lab
```
