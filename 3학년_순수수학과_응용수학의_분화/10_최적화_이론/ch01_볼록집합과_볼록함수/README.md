# 최적화 이론 01. 볼록집합과 볼록함수

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 볼록 함수의 등고선과 최솟값을 그린다.
- 실제 응용 예제: 손실함수가 볼록하면 전역 최적해를 안정적으로 찾는 이유를 본다.
