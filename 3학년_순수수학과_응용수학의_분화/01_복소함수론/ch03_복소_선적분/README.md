# 복소함수론 03. 복소 선적분

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 폐곡선 주변의 복소 벡터장을 따라 적분 방향을 본다.
- 실제 응용 예제: 위상 결함 주변의 순환량을 계산하는 직관을 얻는다.

## 실행
```powershell
jupyter lab
```
