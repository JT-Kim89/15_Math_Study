# 편미분방정식 02. 파동방정식

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 줄의 초기 변위가 양쪽으로 전파되는 모습을 본다.
- 실제 응용 예제: 현악기 줄의 진동을 간단한 수치모형으로 이해한다.

## 실행
```powershell
jupyter lab
```
