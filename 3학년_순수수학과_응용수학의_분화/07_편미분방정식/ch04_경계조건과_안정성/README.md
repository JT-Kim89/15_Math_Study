# 편미분방정식 04. 경계조건과 안정성

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 시간 간격이 너무 크면 수치해가 불안정해지는 예를 비교한다.
- 실제 응용 예제: 시뮬레이션 시간 간격을 안전하게 선택한다.

## 실행
```powershell
jupyter lab
```
