# 실해석학 02. Banach 수축사상

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 수축 반복이 고정점으로 빠르게 모이는 모습을 그린다.
- 실제 응용 예제: 웹 페이지 순위와 같은 반복 갱신 알고리즘의 수렴을 설명한다.

## 실행
```powershell
jupyter lab
```
