# 실해석학 04. 미분과 적분의 연결

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 누적분포와 밀도의 관계를 수치적으로 확인한다.
- 실제 응용 예제: 대기오염 농도 변화율과 누적 노출량을 연결한다.

## 실행
```powershell
jupyter lab
```
