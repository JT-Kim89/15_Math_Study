# 측도론 입문 03. Lebesgue 적분

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: x축 분할과 y축 분할 방식의 적분 근사를 비교한다.
- 실제 응용 예제: 희귀하지만 큰 손실을 갖는 위험 분포의 기대손실을 계산한다.

jupyter lab
