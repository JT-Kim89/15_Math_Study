# 수치해석 입문 02. 방정식의 근

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 이분법과 Newton 방법의 수렴 속도를 비교한다.
- 실제 응용 예제: 수요와 공급이 만나는 균형가격을 수치적으로 찾는다.

## 실행
```powershell
jupyter lab
```
