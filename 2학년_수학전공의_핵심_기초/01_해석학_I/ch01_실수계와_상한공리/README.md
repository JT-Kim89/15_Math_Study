# 해석학 I 01. 실수계와 상한공리

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 단조증가하고 위로 유계인 수열의 수렴을 관찰한다.
- 실제 응용 예제: 반복 개선 알고리즘이 한계값으로 안정되는 이유를 설명한다.

## 실행
```powershell
jupyter lab
```
