# 해석학 I 04. Compactness 입문

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 유한 덮개와 열린공의 직관을 격자로 시각화한다.
- 실제 응용 예제: 센서 배치가 전체 공간을 빠짐없이 커버하는지 근사 점검한다.

## 실행
```powershell
jupyter lab
```
