# 해석학 II 03. 함수열과 균등수렴

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 함수열의 최대 오차가 전체 구간에서 줄어드는지 확인한다.
- 실제 응용 예제: 모바일 앱의 근사 모델이 모든 입력 범위에서 안정적인지 점검한다.

## 이론 보강
