# 선형대수학 II 03. 고유분해와 대각화

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 행렬 반복의 장기 방향이 지배 고유벡터로 정렬됨을 본다.
- 실제 응용 예제: 페이지랭크와 유사한 순위 안정 상태를 추정한다.

## 실행
```powershell
jupyter lab
```
