# 선형대수학 II 04. 특이값분해와 저차원 근사

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 2차원 데이터의 주성분 방향을 찾는다.
- 실제 응용 예제: 고차원 측정값을 정보 손실이 작은 2차원 표현으로 줄인다.

## 실행
```powershell
jupyter lab
```
