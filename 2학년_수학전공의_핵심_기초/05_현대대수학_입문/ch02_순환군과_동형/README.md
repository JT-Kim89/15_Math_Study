# 현대대수학 입문 02. 순환군과 동형

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 생성원의 반복으로 모든 원소가 나오는지 확인한다.
- 실제 응용 예제: 주기적 스케줄이 서로 같은 구조인지 비교한다.

## 실행
```powershell
jupyter lab
```
