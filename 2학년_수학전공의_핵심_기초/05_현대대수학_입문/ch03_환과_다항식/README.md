# 현대대수학 입문 03. 환과 다항식

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 다항식의 근과 나눗셈을 시각화한다.
- 실제 응용 예제: 신호 필터의 영점이 주파수 응답에 미치는 영향을 살핀다.

## 실행
```powershell
jupyter lab
```
