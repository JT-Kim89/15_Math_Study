# 기하학 개론 01. Euclidean 구성

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 점, 직선, 원으로 기본 도형을 구성한다.
- 실제 응용 예제: CAD에서 기본 도형 제약 조건을 수학적으로 표현한다.

## 실행
```powershell
jupyter lab
```
