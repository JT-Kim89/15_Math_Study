## 공부 방법
1. 각 챕터의 `notebook.ipynb`를 연다.
2. Markdown 설명을 읽고 기본 예제를 손으로 먼저 계산한다.
3. 코드 셀을 순서대로 실행하며 그림을 해석한다.
4. 마지막 변형 실험 셀에서 파라미터를 바꾸어 결론의 안정성을 확인한다.
