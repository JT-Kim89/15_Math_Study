# 머신러닝 수학 04. 커널과 특징공간

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 비선형 데이터를 높은 차원 특징으로 보면 분리 가능해짐을 본다.
- 실제 응용 예제: 복잡한 패턴 분류에서 선형 방법을 확장한다.

## 실행
```powershell
jupyter lab
```
