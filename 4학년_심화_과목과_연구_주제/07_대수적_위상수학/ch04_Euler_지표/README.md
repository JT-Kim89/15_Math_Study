# 대수적 위상수학 04. Euler 지표

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: V-E+F가 형태 정보를 담는 예를 계산한다.
- 실제 응용 예제: 메시 모델의 위상 오류를 빠르게 점검한다.

## 실행
```powershell
jupyter lab
```
