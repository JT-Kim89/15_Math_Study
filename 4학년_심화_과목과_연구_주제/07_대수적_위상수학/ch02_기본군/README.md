# 대수적 위상수학 02. 기본군

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 고리 모양 공간에서 수축되지 않는 루프를 그린다.
- 실제 응용 예제: 장애물이 있는 로봇 경로 공간의 서로 다른 루프 유형을 구분한다.

## 실행
```powershell
jupyter lab
```
