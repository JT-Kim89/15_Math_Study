# 계산수학 04. 계산실험 설계

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 입력, 알고리즘, 출력, 평가 기준을 실험 카드로 정리한다.
- 실제 응용 예제: 논문 결과를 재현 가능한 코드 실험으로 옮긴다.

## 실행
```powershell
jupyter lab
```
