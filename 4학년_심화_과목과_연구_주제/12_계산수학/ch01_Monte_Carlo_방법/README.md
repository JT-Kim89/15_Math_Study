# 계산수학 01. Monte Carlo 방법

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 무작위 표본으로 면적과 기대값을 추정한다.
- 실제 응용 예제: 고차원 적분을 확률적 샘플링으로 근사한다.

## 이론 보강
자세한 정의, 핵심 정리, 계산 절차, 증명 관점은 `notebook.ipynb`의 “이론 정리” 섹션에 들어 있습니다.
