# 함수해석학 04. 스펙트럼 직관

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 작용소의 고유성분이 동역학을 어떻게 나누는지 본다.
- 실제 응용 예제: 진동 시스템의 모드 분석을 수학적으로 이해한다.

## 실행
```powershell
jupyter lab
```
