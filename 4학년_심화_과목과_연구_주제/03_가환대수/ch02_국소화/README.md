# 가환대수 02. 국소화

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 한 점 근처에서만 보이는 대수적 정보를 분리해 본다.
- 실제 응용 예제: 복잡한 곡선을 국소 조각으로 나누어 분석한다.

## 실행
```powershell
jupyter lab
```
