# 미분기하학 03. 연결과 곡률

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 구면 위 벡터를 평행이동하면 방향이 달라지는 효과를 본다.
- 실제 응용 예제: 지구 표면 장거리 이동에서 방향 변화가 누적되는 이유를 설명한다.

## 실행
```powershell
jupyter lab
```
