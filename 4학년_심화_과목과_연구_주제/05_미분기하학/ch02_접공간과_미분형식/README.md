# 미분기하학 02. 접공간과 미분형식

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 곡선 위 접벡터가 공간에 붙어 움직이는 모습을 그린다.
- 실제 응용 예제: 로봇이나 드론의 순간 속도 공간을 모델링한다.

## 실행
```powershell
jupyter lab
```
