# 갈루아 이론 02. 분해체

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 다항식의 모든 근이 들어가는 최소 공간을 복소평면에서 본다.
- 실제 응용 예제: 필터의 모든 극점/영점을 포함하는 해석 공간을 이해한다.

## 실행
```powershell
jupyter lab
```
