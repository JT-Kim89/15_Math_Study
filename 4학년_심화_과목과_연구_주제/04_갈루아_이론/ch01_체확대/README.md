# 갈루아 이론 01. 체확대

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 새 근을 추가할 때 수 체계가 확장되는 모습을 본다.
- 실제 응용 예제: 방정식 풀이에 필요한 수의 범위를 체계적으로 추적한다.

## 실행
```powershell
jupyter lab
```
