# 회귀분석 03. 정규화

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 가중치 크기에 벌점을 주면 모델이 어떻게 단순해지는지 본다.
- 실제 응용 예제: 고차원 특성에서 과적합을 줄인다.

## 실행
```powershell
jupyter lab
```
