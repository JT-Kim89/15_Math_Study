# 세미나·캡스톤·졸업논문 04. 글쓰기와 발표

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 문제, 방법, 결과, 한계를 한 장 흐름으로 구성한다.
- 실제 응용 예제: 캡스톤 발표에서 수학적 핵심과 실제 의미를 함께 전달한다.

jupyter lab
