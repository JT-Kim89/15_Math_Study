# 리만기하학 01. Riemannian 계량

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 위치에 따라 길이 측정 방식이 달라지는 예를 그린다.
- 실제 응용 예제: 불균일한 비용 지형에서 최단 비용 경로를 해석한다.

## 실행
```powershell
jupyter lab
```
