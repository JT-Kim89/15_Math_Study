# 금융수학 04. 위험측도

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: VaR와 Expected Shortfall을 표본분포에서 계산한다.
- 실제 응용 예제: 포트폴리오 손실의 꼬리위험을 관리한다.

## 실행
```powershell
jupyter lab
```
