# 고급 최적화 02. 확률적 최적화

이 챕터는 Jupyter notebook으로 공부하도록 구성되어 있습니다.

## 파일
- `notebook.ipynb`: 개념 설명, 코드 읽기, 실행, 변형 실험
- `outputs/`: 노트북 실행 후 생성되는 그림 저장 위치

## 예제 구성
- 기본 개념 예제: 미니배치 그래디언트의 흔들림과 수렴을 비교한다.
- 실제 응용 예제: 대규모 데이터에서 빠른 학습 업데이트를 수행한다.

## 실행
```powershell
jupyter lab
```
